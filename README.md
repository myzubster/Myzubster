## Progetto principale: MyZubster

[MyZubster](https://www.myzubster.com/) è un ecosistema open source in evoluzione con percorsi dedicati a Marketplace, Seller, Community, Knowledge Explorer, LIFE Pilot, Metaverso e Comic Universe.

Il mio lavoro comprende sviluppo e test del prodotto, API, autenticazione, integrazioni GitHub e AI, analytics e flussi utente.
